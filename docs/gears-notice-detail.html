[New] User Guideline for Flexibility/Pooling
Lee Hyn-ju
2026-02-25
51 views
Attachment PDF KR GEARs User Guidance - Flexibility(Ver.0).pdf

We are pleased to inform you that a new Flexibility function has been launched in KR GEARs to support FuelEU Maritime compliance management.

This function enables users to:

  • Register and upload Compliance Balance (CB) information
  • Submit CB data for verification
  • Create and simulate pooling scenarios among vessels
  • Allocate CB amounts per vessel within a pool
  • Validate pooling conditions before submission
  • Request verifier confirmation for the selected pooling scenario

The Flexibility module allows companies to evaluate various pooling options in advance and select the most optimal compliance strategy prior to formal verification.

Joint Transaction Feature

A joint transaction feature has been introduced between companies. This feature entails the following process:

  • Companies wishing to sell CBs can register relevant CB information in the system.
  • Companies wishing to purchase CBs can propose transactions based on the registered information.
  • Selling companies can review proposals submitted outside of KR GEARS, select the best proposal, and finalize their intent to transact.

This system does not provide the ability to conclude or formalize contracts. It simply serves as a systematic platform for coordinating CB transaction intentions between companies. Once both parties confirm the transaction, the agreed CBs are reflected in the joint transaction scenario, which can include additional vessels for an optimized joint transaction structure.

For detailed procedures and step-by-step instructions, please refer to the official user guidance attached above.
